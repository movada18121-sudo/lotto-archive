# live-draw: brief สำหรับ Antigravity / Gemini

ไฟล์นี้สรุปงานทั้งหมดให้ AI ที่มาช่วย (Antigravity, Gemini) เข้าใจตรงกับ Claude และเจ้าของโปรเจกต์
Antigravity โหลดไฟล์นี้อัตโนมัติ (`tools/agy.ps1` คัดลอกไปไว้ในโฟลเดอร์งานทุกครั้งที่เรียก)

## โปรเจกต์คืออะไร
- overlay สำหรับไลฟ์ TikTok แนวตั้งกลุ่ม "สายมู" (บรรยากาศศาลเจ้า ไหว้พระ ขอพร) แสดงผ่าน OBS
- ผู้ชมได้ **เลขสุ่มฟรี** เมื่อคอมเมนต์ "สาธุ", ไลก์รวมถึงเป้า, รอบตามเวลา หรือแอดมินกด
- ผู้ส่งของขวัญได้ **คำขอบคุณ + การ์ด/เอฟเฟกต์เท่านั้น** ของขวัญไม่มีผลกับเลขเลย (เพื่อไม่ให้เข้าข่ายการพนันตามกฎ TikTok และกฎหมายไทย)
- เลขเป็นเลขสุ่มด้วยคอมพิวเตอร์ เพื่อความบันเทิง ไม่มีรางวัล ไม่เกี่ยวกับผลสลากใดๆ

## แบ่งงานกัน
- **Claude** คุมงานหลัก: เขียนโค้ด, รวมภาพเข้า overlay, ตรวจผล, commit
- **Antigravity / Gemini** ทำ: สร้างภาพ (ผ่าน subagent `image-generator`), วิจารณ์ดีไซน์เมื่อถูกขอ
- อย่าแก้โค้ด, `config.json`, `logs/` หรือไฟล์ใน repo เว้นแต่คำสั่งบอกชัดเจน
- ภาพที่สร้าง: บันทึกในโฟลเดอร์ปัจจุบันด้วยชื่อไฟล์ตามที่สั่ง แล้วตอบกลับเป็น path ของไฟล์
- สร้างทีละภาพตามที่สั่ง รอให้ subagent ทำเสร็จก่อนจบงาน

## ห้ามเด็ดขาดในภาพ
- ตัวหนังสือ ตัวอักษร ตัวเลข ลายเซ็น ลายน้ำ (ภาษาไทยที่ AI วาดเพี้ยน ข้อความทั้งหมด overlay ใส่เอง)
- ใบหน้าคน, คน, ภาพเทพ/พระ/รูปปั้นแบบเห็นหน้าชัด
- ลอตเตอรี่, สลาก, เงิน, ธนบัตร, เหรียญ, ลูกเต๋า, วงล้อเสี่ยงโชค
- โลโก้หรือแบรนด์จริง

## สไตล์
- ศาลเจ้าไทย-จีนยามค่ำ สงบ ขลัง อบอุ่น · แสงเทียน โคมแดง ควันธูปบางๆ ลายแกะสลักทอง
- สี: แดงเข้ม `#8e1414` `#b3261e` · ทอง `#f5c542` `#ffe08a` `#a8761a` · พื้นมืด `#1a0503`
- ภาพเหมือนจริงแบบ cinematic แสงนุ่ม รายละเอียดสูง

## ผังจอ (1080×1920 แนวตั้ง) — พื้นที่ที่ต้องเว้นให้มืดและโล่ง
| ช่วงความสูง (px) | สิ่งที่ overlay วางทับ |
|---|---|
| 0–200 | ป้าย "เพื่อความบันเทิงเท่านั้น" |
| 200–330 | แถบไลก์ / เวลาถอยหลัง |
| 420–1320 | กลางจอ: กระบอกเซียมซี + ตัวเลขสุ่ม 3 หลัก |
| 1500–1920 | การ์ดขอบคุณ + แถบ "พิมพ์ สาธุ" |

## หลังได้ภาพ (Claude ทำ)
- ลบพื้นเขียว: `py tools/keyout.py assets/siamsi.png assets/siamsi_cut.png` (เช่นเดียวกับ frame → `frame_cut.png`)
- overlay หยิบไฟล์เองอัตโนมัติ: `assets/bg.(png|jpg|webp)`, `assets/siamsi_cut.png`, `assets/frame_cut.png`
- ดู overlay พร้อมฉากหลัง: `http://127.0.0.1:5181/overlay?bg=1` (รัน `py server.py` ก่อน)

## หมายเหตุเทคนิค
- `image-generator` ได้ภาพ 768×1376 สำหรับ 9:16 · ภาพมักไปอยู่ที่ `~/.gemini/antigravity-cli/brain/<id>/` ถ้าไม่ได้บันทึกในโฟลเดอร์งาน
- ห้ามใช้คำว่า ทำนาย / คาดคะเน / เลขเด็ด ในข้อความใดๆ ของโปรเจกต์
