# ต้นแบบระบบสุ่มเลขบนไลฟ์ TikTok (live-draw)

ต้นแบบตามรายงาน `reports/ระบบไลฟ์ TikTok สุ่มเลขจากของขวัญ.md` — เวอร์ชันที่ลดความเสี่ยงแล้ว

| เหตุการณ์ | ได้อะไร |
|---|---|
| คอมเมนต์มีคำว่า "สาธุ" | เลขสุ่มส่วนตัว ฟรี (1 คน / 5 นาที) |
| ไลก์รวมครบทุก 500 | เลขสุ่ม "รอบรวมพลัง" |
| ทุก 10 นาที | เลขสุ่มรอบตามเวลา |
| ปุ่มในแผงควบคุม | รอบพิเศษจากแอดมิน |
| ของขวัญ / ติดตาม / แชร์ | **การ์ดขอบคุณ + เสียงเท่านั้น ไม่สุ่มเลข** ของขวัญใหญ่ได้แค่กรอบทอง/เอฟเฟกต์ |

ป้าย "เพื่อความบันเทิงเท่านั้น · ไม่มีรางวัล" อยู่บนจอตลอด

## ใช้ Python ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม

```
py server.py
```

- แผงควบคุม: http://127.0.0.1:5181/control (มีปุ่มจำลองคอมเมนต์/ของขวัญ/ไลก์ ไว้ซ้อม)
- overlay สำหรับ OBS: เพิ่ม **Browser Source** → URL `http://127.0.0.1:5181/overlay` ขนาด 1080×1920 (พื้นหลังโปร่งใส)
  - `?bg=1` แสดงฉากหลังแดงทอง (ใช้แทนฉากได้เลยถ้าไม่มีกล้อง)
  - `?tts=1` อ่านคำขอบคุณ/เลขออกเสียงด้วยเสียงไทยของเครื่อง (ต้องมีเสียงภาษาไทยใน Windows และ OBS บางรุ่นอาจไม่ออกเสียง — ถ้าไม่ได้ ให้ใช้ TTS ของ TikFinity แทน)

## ต่อกับ TikTok จริง

1. ติดตั้งและเปิด **TikFinity** desktop แล้วเชื่อมกับบัญชี TikTok
2. รัน `py server.py` — มันจะต่อ `ws://127.0.0.1:21213/` เอง (ป้ายในแผงควบคุมจะเปลี่ยนเป็น "เชื่อมต่อแล้ว")
3. ถ้า TikFinity ปิด/หลุด ระบบลองต่อใหม่ทุก 5 วินาที ระหว่างนั้นยังกดสุ่มเองได้

> ยังไม่ได้ทดสอบกับ TikFinity จริง ชื่อฟิลด์ที่อ่านรองรับทั้ง schema เก่าและใหม่ของปี 2026 แต่ควรดูข้อความจริงที่พอร์ต 21213 อีกครั้งตอนลองไลฟ์แรก

## ตั้งค่า — `config.json`

คำสำคัญ (`keywords`), cooldown, เป้าไลก์, รอบเวลา, จำนวนหลัก (`digits`), ระยะเวลาการ์ดบนจอ, ขนาดคิว, เกณฑ์กรอบทอง (`gift_tiers` หน่วย diamond) และข้อความป้ายแจ้งเตือน

## ความโปร่งใส (commit-reveal)

- ทุก session สุ่ม seed ลับ แล้วโชว์ `commit` (SHA-256 ของ seed) ในแผงควบคุมตั้งแต่ต้น — ประกาศค่านี้ในไลฟ์ได้
- เลขรอบที่ n = HMAC-SHA256(seed, n) mod 1000
- จบไลฟ์กด "เปิดเผย seed" → ทุกคนตรวจได้ว่าเลขไม่ได้ถูกแก้: `py verify.py`
- log ทุกเหตุการณ์อยู่ใน `logs/draws.jsonl` (ต่อท้ายอย่างเดียว)

## ทดสอบ

```
py -m unittest -v
```

มี test ยืนยันว่า: ของขวัญ/ติดตาม/แชร์ไม่เรียกการสุ่มเลย, `thanks.py` ไม่ import ตัวสุ่ม, combo ของ Rose นับครั้งเดียว, cooldown, เป้าไลก์, คิวเต็ม และ log ที่ถูกแก้จะตรวจไม่ผ่าน

## ไฟล์

- `server.py` — เว็บเซิร์ฟเวอร์ + ตัวจัดคิวขึ้นจอ (SSE)
- `hub.py` — แยกเหตุการณ์เข้า 2 ท่อ
- `draw.py` — ที่เดียวที่สร้างเลขสุ่ม
- `thanks.py` — สร้างคำขอบคุณ (ห้ามแตะตัวสุ่ม)
- `tikfinity.py` — WebSocket client ต่อ TikFinity
- `overlay.html`, `control.html`, `verify.py`, `test_core.py`
